1. 本機開啟 UI：

  make grafana-port-forward

2. 查看 Backtest Worker metrics 圖表：

  Dashboards → 資料夾 **Backtest** → **Backtest Worker**

  面板含：Pod CPU / Memory / CPU throttling、重啟、OOM、存活時間

3. 查看 log：

  Explore → **Loki** → {namespace="{{ include "grafana.dashboardNamespace" . }}", app="task-worker"}

4. 重新部署 dashboard（修改 JSON 後）：

  make helm-install-grafana

  Helm 會更新 ConfigMap；Grafana Pod 因 checksum 自動重啟並載入新 dashboard。
